# Screenshots for pull requests

Images linked from pull request descriptions. They are taken from the UI's mock backend
(`trunk serve` in `ui/`, see `ui/README.md`), so the values, the peer addresses and the
`(mock)` errors are made up. This branch has no history in common with the code and is never
merged.

- `rebuild/`: the state of the `rebuild` branch (PR #79).
- `ui-polish-1/`: before and after images of the fixes in the `ui-polish-1` branch.
- `rename-zeal/`: before and after images of the rename to Zeal.
